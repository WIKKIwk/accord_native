# Flutter V2 to Expo V4 component map

Use with [COMPONENT_CATALOG.md](COMPONENT_CATALOG.md). V2 and V4 evidence paths are relative to the V4 repo. V2 begins `../accord_mobile_v2/`. Import paths use the V4 `@/` alias for `src/`. An extensionless import intentionally leaves platform resolution to Metro where the platform siblings exist.

A match can be a direct component, a composition or a role-scoped analogue. Read the Android and iOS columns before copying a pattern. Where the same V2 surface has divergent V4 equivalents, keep the scope from the source and use B3 to compare the current implementations.

## B5. ESLint proposal

Use `no-restricted-imports` with named import restrictions in new route/page/screen implementation files. Match `src/app/**/*.{tsx,jsx}` and the role-owned `*Screen.*` or `*Page.*` view files. Scope this to direct value imports. The messages below are the proposed rule text.

| Import module | Direct imports to restrict | Message |
| --- | --- | --- |
| react-native | Button, FlatList, SectionList, RefreshControl | Use the role's button or list adapter. Keep native scroll, refresh and paging ownership in that adapter. |
| react-native | Modal, Alert | Use the registered role sheet or confirmation adapter so the route owner controls dismissal and result. |
| react-native | TextInput | Use OrdersHeader/OrdersSearchInput for search or the role form-field adapter for editing. |
| @expo/ui/community/bottom-sheet | BottomSheet | Open the role sheet adapter or useNativeSheet. Keep detents and dismissal policy in the adapter. |
| @expo/ui/jetpack-compose | ModalBottomSheet, AlertDialog, BasicAlertDialog | Use the established dialog or sheet adapter. Direct native imports belong in the platform presentation layer. |
| @expo/ui/swift-ui | BottomSheet, Alert | Use the role presentation adapter for sheet/dialog lifecycle and keyboard policy. |
| @expo/ui or native @expo/ui entry | Button, IconButton, TextField, OutlinedTextField, FilterChip, List when used as a generic screen primitive | Use the matching catalog component or follow a documented platform-specific recipe for this screen. |
| react-native-drawer-layout / expo-router/unstable-native-tabs | Drawer, NativeTabs | Use RoleDrawer or RoleTabs. Keep labels, badges, route access and gestures with the role navigation owner. |

Apply narrowly to new or touched screens after recording existing platform adapters in overrides. Adapters include native list and sheet hosts, role navigation wrappers and the verified Preparation home native list recipe. Permission alerts, hardware flows and route-header configurations can keep a scoped exception when the catalog identifies that path. The proposal leaves the current ESLint configuration intact. See `eslint.config.js:1`.
