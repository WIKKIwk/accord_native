# Boyoqchi UI contract

Source: V2 `f11910bb`. The role uses `boyoqchi.access`. Home and Astatka each call `boyoqchiReturnedPaintRequests(limit: 100)` independently. They display the first page only, with loading, error/retry, empty/refresh and pull-to-refresh states. Refresh collapses the expanded card. Only one card can be expanded at a time. The Home screen also loads `adminApparatus(limit: 10000)` separately; on failure or missing catalog entries technical IDs are hidden as `—`.

## Home: `BoyoqchiHomeScreen`

Source `lib/src/features/boyoqchi/presentation/boyoqchi_home_screen_widgets_part_01.dart` and `boyoqchi_home_screen_helpers_part_02.dart`. Entry: `AppRoutes.boyoqchiHome`. Title `Bo‘yoqchi`; loading indicator; error `Ma’lumotlar yuklanmadi` and `Qayta yuklash`; empty `Qaytarilgan bo‘yoq ma’lumotlari hali yo‘q` and `Yangilash`. Each expandable card title is the request order name and code, or available fallback. Expanded content is `Order`, `Operator`, `Time`, `Location`; nonempty items are grouped in their original order under `Rasxot` and `Astatka`, and categories `Ranglar`, `Laklar`, `Spirtlar` or the original category. Entries show the name and populated fields, formatted to three fractional digits at most.

## Astatka: `BoyoqchiAstatkaScreen`

Source `lib/src/features/boyoqchi/presentation/boyoqchi_astatka_screen.dart`. Entry: `AppRoutes.boyoqchiAstatka`. Title `Astatka`; error `Astatka ma’lumotlari yuklanmadi` and `Qayta yuklash`; empty `Hisoblangan Astatka ma’lumotlari hali yo‘q` and `Yangilash`. Expanded rows: `Order kodi`, `Operator`, `Sana va vaqt`. If an image exists, tapping it opens the full-screen image dialog with download; download shows `Rasm Photos ga saqlandi.` or `Rasm yuklab olinmadi`. A waiting request shows `Qaytarilgan bo‘yoq qiymatlari kiritilmagan. Rasmdagi qiymatlarni Bo‘yoqchi to‘ldirishi kerak.` and `Qaytarilgan bo‘yoq`, which opens the sheet. A completed calculation shows `Rasxot jami Mix`, `Astatka jami Mix`, `Rasxot spirt miqdori`, `Astatka spirt miqdori`, `Yakuniy ishlatilgan spirt`, `Rasxot sof bo‘yoq miqdori`, `Astatka sof bo‘yoq miqdori`, `Yakuniy ishlatilgan bo‘yoq`, each in kg. Missing calculation shows `Ushbu eski hisobot uchun hisoblash ma’lumoti mavjud emas.`

## Returned paint sheet: `ReturnedPaintSheet`

Source `lib/src/features/boyoqchi/presentation/widgets/returned_paint_sheet*.dart`, `returned_paint_draft_store.dart`. Entry: waiting Astatka request. Load actor/request-scoped draft, with request image as initial image. Title `Qaytarilgan bo‘yoq`; back returns from a selected color to the palette, or closes the sheet. Existing image opens a full-screen preview without download from within this sheet. Boyoqchi does not get image edit actions. Tabs `Rasxot`, `Astatka` retain the selected usage and values. Palette has `Ranglar`: `Mix`, `Pantone`, `Oq`, `Sariq`, `Qizil`, `Ko‘k`, `Tilla`, `Kumush`, `Qora`; `Laklar`: `Lak`; `Erituvchilar / spirtli suyuqliklar`: `Spirtlar`. Entering a palette item opens its fields, with filled/partial status on the palette. Numeric input accepts only digits and one decimal comma or point. Standard fields are `Mix`, `1w Oq`, `7w Oq`, `Qora`, `Sariq`, `Qizil`, `Ko‘k`, `Spirt`; Lak fields `OPV lak`, `MAT lak`; Spirtlar fields `Aralashmalar`, `Etil`, `Metoxil`, `Rasvavitel`, `Izopropel`. Pantone has separately stored Pantone and Pantone Mix named fields. Dynamic `Pantone+` and `Mix+` open a dialog titled `$paint maydoni nomi`, with `Majburiy nom`, `Masalan: Pantone Blue`, `Qiymat`, `Masalan: 12.5`, `Bekor qilish`, `Qo‘shish`; it only accepts a nonempty name and finite nonnegative numeric value. A duplicate name shows `Bu nom allaqachon qo‘shilgan.`

`Saqlash` checks invalid values first (`Qaytarilgan bo‘yoq qiymatlarini to‘g‘ri raqamda kiriting.`), then at least three filled fields in each tab (`Har bir tabda kamida 3 ta maydon to‘ldiring. Rasxot: $rasxotCount/3, Astatka: $astatkaCount/3.`). On success it sends request ID and both tabs' items, clears the draft, refreshes Astatka, and closes. On failure it displays the API error or `Qaytarilgan bo‘yoq saqlanmadi`. Saving blocks back and dismissal.

## Shared navigation

`BoyoqchiNavigationDrawer` has `Bo‘yoqchi bo‘limlari`, Home (`homeNavTitle`), `Astatka`, `Chat`, Profile (`profileTitle`) and shared logout confirmation. Home and Astatka use replacement navigation. `BoyoqchiDock` declares Home, Astatka and Profile; the shared `RoleDock` appends Chat as the fourth destination with an unread dot. Selecting an already active destination does nothing. The Chat list shows that dock with Chat selected; a conversation uses its composer in place of the dock. Chat and Profile reuse their existing screens. No FAB or search field exists on these Boyoqchi surfaces. Locale getters and Urdu-aware text are used as in source; avoid adding words.
